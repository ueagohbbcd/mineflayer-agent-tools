# 试验区

这里的代码是测试和试玩中用到的控制逻辑，**还不是仓库例程**：实机验证还少，接口随时会改。玩家项目可以复制过去用、改。

升级规则：试验区的代码在两次真实试玩中用过、没有导致死亡或控制者卡住，就整理成例程；验证记录留在代码旁边（下面的表）。

每件事只有一种做法：导航用 `goto`，还手和进食是反射（`reflexes.mjs`，基于 mineflayer-pvp 和 mineflayer-auto-eat）。第二种做法要有实机证据说明它在某种情况下更好才加进来。

这里的函数都自己遵守退出约定：入口和每次 await 之后检查 `signal`，已中止就抛出，不再做游戏动作。只调用它们的任务不需要写退出代码。

| 文件 | 作用 |
| --- | --- |
| `reflexes.mjs` | 三个反射：`defend`（拿最好的武器用 mineflayer-pvp 还手，血少就逃开）、`escape`（头在方块里就用 mineflayer-tool 换工具挖开，或后退）、`eat`（用 mineflayer-auto-eat 选食物、吃、换回原物品）；带 `check` 的可以用在任务的安全点 |
| `idle.mjs` | 没有作业时的循环：头在方块里就出来、被打就还手、在水里按住跳浮在水面、饿了就吃 |
| `danger-preempt.mjs` | 观察器 `dangerPreempt`：被敌对生物打且血量低于 12 时让 `defend` 抢占，窒息时让 `escape` 抢占；之后结束作业 |
| `goto.mjs` | `goto(bot, ctx, [x, y, z], { range, stallMs, checks })`：用当前寻路设置走到坐标，每 0.5 秒检查一次；到达按 goal 判定核对脚和脚上一格；连续 3 次无路或 `stallMs`（20 秒）不前进时抛错，错误带寻路最后状态。`checks` 默认为空；给了才在每次检查时设安全点（进阶用法） |
| `craft.mjs` | `craftChecked(bot, ctx, name, count, table)`：按物品名合成并核对数量增加 |
| `danger-alerts.mjs` | 旧的危险观察器（TNT、膨胀的苦力怕、飞行物、被盯上），素材，未接入 |

## 实机记录（2026-11-08，本地 1.21.1 官方服务器，普通难度，模板 main）

每项跑一次，除非另注。

| 场景 | 结果 |
| --- | --- |
| `goto` 15 格 | 4.5 秒到达；`wait` 随后立即返回，报告有状态、周围、背包 |
| 出生点在方块里时 `goto` | 20 秒不前进后抛错（场景问题：tp 到了沙岩里） |
| 寻路中杀掉 `run` 命令 | 作业继续；`cancel` 后角色停下（之后惯性漂移约 0.2 格） |
| 血 11 时刷一只僵尸 | 被打到 8 血时 `defend` 抢占，还手 7 次后"周围安全"，作业以"被 defend 抢占"结束，转 idle。当时手持面包没换剑，之后给 `defend` 加了换武器，未再测 |
| 任务里 `safepoint({ eat: 'restart' })` + 饥饿效果 | 饥饿到 14 时任务退出、吃两块面包、任务从入口开始第 2 次尝试，`run` 命令全程没断 |
| 任务中 `/kill` | 作业以死亡结束，没有重启；重生后 idle 才开始；报告有死亡位置和重生位置 |
| 不理退出信号的任务 + `cancel` | 5 秒后标为卡住并唤醒，仍是控制者；12 秒后任务返回，作业记为"很久才退出"，再唤醒，转 idle |
| 没人 wait 时私聊 | 下一次 `wait` 立即返回，原因是私聊，报告的聊天段有原文；有 wait 时点名也会唤醒 |
| 头部所在格放泥土 | 受到 `in_wall` 伤害，`escape` 抢占，挖开后作业结束 |
| 水下 7 格（idle） | 氧气低于 15 才按跳时角色在水面和水下来回，没有掉血；改成在水里一直按跳，未再测 |
| 连续 20 次合成（2×2 和工作台混合） | 不处理：2 次都在第 9 次左右开始"数量不变"、"缺材料"、`updateSlot` 超时，合成格残留物品。每次合成后清理：2 次全部成功，bot 背包和服务器一致。清理已放进 `lib/crafting-fix.mjs`（`fixCrafting` 包住 `bot.craft`），再测 2 次全部成功 |
| 伤害类型 | 看到 `generic`、`mob_attack`（带来源 zombie）、`in_wall` |

## 接入生态插件后（2026-11-09）

| 场景 | 结果 |
| --- | --- |
| 血 7.8 时两只戴头盔的僵尸，`defend` 用 pvp | 换上铁剑，被打到 6 血以下后逃开，"周围安全"后交回；两只僵尸都没死，之后 idle 再次还手，最低到 1.8 血。逃跑时机和阈值都要再调 |
| 满血时一只僵尸，idle 用 pvp | 僵尸被杀，没掉血；pvp 跟着目标走了几十格 |
| 饥饿效果 + 任务安全点，`eat` 用 auto-eat | 背包有面包和腐肉，吃了面包，任务从入口开始第 2 次尝试 |
| 头部所在格放泥土，`escape` 用 tool | 换上铁锹挖开 |
| 捡起铁胸甲（armor-manager） | 自动穿上 |
| collectblock 收集 3 个原木 | 只走路的设置下一个都不挖（它只破坏 movements 允许挖的方块）；任务里换成能挖的设置后收集 3 个，退出后恢复只走路 |
| pvp、collectblock 的寻路设置 | 两个插件每次调用都会把 Pathfinder 换成自己能挖的设置；模板把它们的 `movements` 设为 null 后，打完架仍是只走路 |

还没测：骷髅等远程生物下的 `defend`、夜里的 idle、`defend` 打不过时的逃跑、`danger-preempt` 的 12 血阈值是否合适（没有依据，等下一次试玩）。

另见：Mineflayer 的 `bot.oxygenLevel` 会被附近其他实体的空气值覆盖（实测出现 400、393），状态报告和 idle 改用 `oxygenOf(bot)` 读自己的值。
